# iOS v1 출시 범위와 진행표

사용자의 2026-11-17 지시에 따라 Codex가 정한 작업 기준이다. 수량과 설정은 목표이며 현재 구현량과 구분한다. 상위 방향은 RELEASE_PLAN.md를 따른다.

## 출시 분량

- 기본 무료 iOS 게임. Windows에서 공통 게임과 모의 플랫폼 검증까지, Mac에서 실제 네이티브 통합·검증·TestFlight를 완료한다.
- 한국어(ko), 영어(en), 일본어(ja)의 UI와 서로 다른 단어 콘텐츠를 제공한다. UI 언어와 퍼즐 언어를 분리하며 언어별 진행도를 보관한다. 코인·구매 권한·오디오 설정은 공통이다.
- 언어별 일반 450레벨(15레벨씩 30챕터) + 별도 일일 퍼즐 30개. 총 1,350 일반 레벨과 90 일일 퍼즐을 목표로 한다. 번역판을 새 레벨로 세거나 동일 보드를 돌려 수량을 채우지 않는다.
- 하루 일반 15레벨과 일일 1개, 약 15~25분을 가정한 30일 분량이다. 강제 일일 제한은 없고 빠른 사용자는 일찍 소진할 수 있다. 시간·리텐션·매출을 보장하는 수치가 아니다.
- 첫 30일 일일 퍼즐은 설치 후 일차 기준으로 순환하고 재플레이 가능하다. 보상은 사용자가 실제 도달한 로컬 일자와 퍼즐 ID로 1회 관리하며 시간 역행 시 중복 지급하지 않는다. 서버 없는 시간 조작 방지는 완전하지 않다.
- 출시 시 초대·친구·실시간 대전·서버 계정·Firebase·Game Center·시즌패스·구독·배너 광고는 제외한다. Game Center는 실제 수요 확인 후 별도 도입한다.
- 청소년·성인에게 편안한 단어 퍼즐을 제공한다. 아동 전용 앱으로 기획하지 않는다. 스토어 연령 등급은 실제 콘텐츠·광고 및 Apple 질문에 따라 기입한다.

## 언어와 콘텐츠 기준

- ko: NFC로 조합한 한글 음절 한 칸, 2~5음절 일상 명사 중심. 어색한 음역·활용형·억지 단어를 제외한다.
- en: 대문자 A~Z 한 칸, 3~7자 중심. 쉬운 보너스에 한해 명시적으로 승인한 2자를 허용한다.
- ja: NFC 히라가나 한 글자 한 칸, 2~6자 일상 명사 중심. 작은 가나도 한 칸이며 탁점·반탁점은 조합 완료한 글자를 사용한다. v1 퍼즐에는 한자·로마자·임의 히라가나 외래어 변환을 섞지 않는다.
- 언어별 원어민 또는 이에 준하는 검수가 출시 게이트다. AI가 생성한 어휘·뜻풀이를 검수 완료 자료라고 부르지 않는다.
- 향후 15개 언어는 키 기반 문구·로케일 목록·개별 콘텐츠 팩을 추가하도록 설계한다. 출시 때 미지원 언어 버튼을 노출하지 않는다. RTL·복합문자 분할은 해당 언어 도입 때 검증한다.
- 최초 실행은 기기 언어의 ko/en/ja를 선택하고 그 외에는 en을 사용한다. 설정에서 수동 변경한다. 미번역 UI 키는 en으로 폴백한다.
- 보드는 최대 7×7, 고유 랙 글자는 최대 10종을 기본 제작 한도로 한다. 실제 작은 화면 조작 검사에서 한도를 재평가한다.
- 1~30레벨은 2~3단어, 31~150은 3~4단어, 151~300은 4~5단어, 301~450은 4~6단어를 기본값으로 한다. 길이와 어휘 친숙도로 난이도를 조절한다. 두 레벨 연속 급격한 난도 상승을 피하고 어려운 레벨 뒤에는 쉬운 레벨을 둔다.
- 정답 전체 목록은 개발용이다. 출시 UI는 미완성 정답을 노출하지 않고 완성한 단어·남은 개수만 보여준다.

## 초기 경제·광고·상품 설정

아래는 밸런스 검증 전 기준안이며 현재 런타임의 기존 보상을 아직 바꾼 것은 아니다. 이후 숫자는 한 설정에서 관리한다.

| 항목 | v1 기준안 |
|---|---|
| 시작 코인 | 120 |
| 일반 정답 1개 | 별도 코인 없음; 연출·진행 보상 |
| 일반 레벨 최초 완료 | 10코인 |
| 보너스 단어 | 2코인, 레벨당 보상 5개까지; 이후 발견은 기록 |
| 한 칸 힌트 | 60코인 |
| 일일 퍼즐 최초 완료 | 30코인; 일반 완료 보상과 중첩하지 않음 |
| 일일 목표 | 일반 5레벨 완료 시 20코인 1회 |
| 선택형 보상 광고 | 성공한 보상 콜백당 60코인, 일일 최대 6회 |
| 광고 제거 | 전면 광고 제거; 자발적 보상 광고 유지·구매 전 설명 |
| 코인 상품 | 600 / 1,800코인 두 종류; 현지 가격은 StoreKit 조회값만 표시 |

일반 15레벨+일일+목표만으로 하루 200코인, 힌트 약 3.3회가 기본 공급된다. 보너스·광고·구매는 추가다. 실제 힌트 수요를 계측해 조절한다. 최초 출시 후보 가격은 App Store Connect 설정 단계에서 정하고 가짜 현지가격을 하드코딩하지 않는다.

첫 15레벨 완료 및 누적 플레이 15분이 모두 지나기 전 전면 광고를 요청하지 않는다. 이후에도 광고 사이 최소 180초·일반 4레벨 완료를 모두 충족하고, 세션 최대 3회·로컬 일일 최대 8회로 제한한다. 보상 광고 뒤 180초는 전면 광고를 쉬고 게임 중에는 광고를 띄우지 않는다. 세션 재시작으로 일일 제한을 초기화하지 않는다.

구매·광고 없이 모든 퍼즐을 풀 수 있다. 에너지·목숨·시간 제한·자동 구매창·보상 없는 강제 영상·의도적 불가능 레벨은 넣지 않는다. 힌트가 필요한 순간에 코인 사용·자발적 광고·상점·그대로 플레이를 명확히 구분한다. 광고 실패·재고 없음·오프라인은 진행을 막지 않는다.

## 1~9 순서와 완료 게이트

| 순서 | 작업 | 현재 상태 | 완료 게이트 |
|---|---|---|---|
| 1 | 범위·비주얼·에셋·콘텐츠 계약 확정 | 이 문서와 VISUAL_DIRECTION.md로 확정 | 수량·언어·과금·제외 범위 기록 |
| 2 | 조작 화면·언어 기반·오디오·설정 | 정답 숨김·오디오 구현, 언어·배치 미완료 | 정답 숨김, 세 언어 UI, 보드/랙 접근성, BGM·효과음·볼륨·중단 처리 |
| 3 | 콘텐츠 제작과 검증 | Gemini 1차 요청 준비 | 언어별 450+30, 어휘·라이선스·보드·중복·순서·표시 검증 |
| 4 | 플레이·재화 밸런스 | 기준안 확정, 미적용 | 설정 일원화, 공급/소모 시뮬레이션, 플레이 테스트로 보정 |
| 5 | 일일 퍼즐·목표·가벼운 수집 | 미구현 | 반복/날짜 역행/언어 변경/재실행 중복 보상 방지 |
| 6 | 상점·IAP 공통 계층 | 미구현 | 구매·보류·실패·복원·중복 거래와 재실행 모의 검사 |
| 7 | 광고 공통 계층 | 미구현 | 명시적 보상·중복 콜백·빈도·실패·오프라인·광고 제거 검사 |
| 8 | 통합 QA·저장 마이그레이션 | 기존 기본 검사만 완료 | 출시 데이터 전량 검사, 3언어 저장 분리, 반복 플레이·모의 플랫폼 회귀 |
| 9 | 스토어·Mac 인계 | 계획만 있음 | 지원/개인정보 문서, SDK/상품/광고 설정, 빌드 인계 문서 |

단계 2의 현재 실행 결과는 AUDIO.md와 GODOT_PLAYABLE.md에 기록했다. 48초 BGM·효과음 10종·개별 음량/전체 음소거 저장과 포커스/앱 중단 제어를 구현하고 Windows 엔진에서 검사했다. 세 언어 런타임 UI·언어별 진행 분리와 고정 조작 배치는 아직 완료 전이다. 경제 표의 수치는 단계 4 전에는 기존 게임 보상에 적용하지 않는다.

1~9 완료가 iOS 출시 완료를 뜻하지 않는다. 실제 iOS 플러그인 링크·서명·결제·복원·광고·동의·기기 성능·TestFlight는 Mac 게이트다. 단계 6 이전에 Windows에서 Godot/플러그인 호환성을 조사해 버전을 고정하고, 실제 iOS 통합 가능 여부의 최종 판정은 Mac 인계 단계에서 수행한다.

## 협업과 합격 기준

Gemini에는 아트 명세 보완·문구·어휘와 콘텐츠 묶음을 맡긴다. 현 단계 요청서는 GEMINI_LAUNCH_CONTENT_TASK.md다. 1차로 작은 표본을 검수한 뒤 같은 계약으로 분량을 늘린다. 원문은 ZIP 대신 경로가 표시된 UTF-8 텍스트로 전달한다.

Codex는 범위 확정, 실제 코드 통합, 정규화·배치·중복·플레이 가능성 검사, 저장·경제·플랫폼 경계를 관리한다. 의존 결과가 오기 전에도 독립 작업을 진행하되 검수 전 데이터를 출시 자산으로 승격하지 않는다. 실행 검증·정적 검토·실기기 미검증을 구분하고 수익·리텐션의 가정과 실측을 구분한다.

# Word Tiles - Game Design Spec

## 코어 루프
1. 보드의 빈 칸 구조를 관찰한다.
2. 하단 타일 랙에서 글자를 스와이프해 단어를 만든다.
3. 정답 단어면 보드 칸이 채워지고, 보너스 단어면 코인을 획득한다.
4. 획득 코인으로 힌트를 사용하며 다음 레벨로 진행한다.

## 핵심 시스템

### 1. 타일 수량 규칙
- 각 글자의 수량은 "남은 빈 칸" 기준으로 계산한다.
- 이미 채워진 교차 칸은 다시 차감하지 않는다.

### 2. 보너스 단어
- 보드 정답이 아닌 유효 단어를 제출하면 보너스 처리한다.
- 보너스 단어는 코인을 주지만 보드 상태는 바꾸지 않는다.

### 3. 저장
- 현재 레벨
- 보유 코인
- 소리 on/off
- 채워진 좌표
- 찾은 보너스 단어

### 4. UX 목표
- 힐링 톤의 밝은 UI
- 모바일 세로 화면 우선
- 실수 취소가 자연스러운 스와이프
- 정답/보너스에 명확한 피드백

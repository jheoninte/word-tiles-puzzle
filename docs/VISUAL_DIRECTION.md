# v1 비주얼 방향과 에셋 명세

## 고정 방향: 햇살이 드는 단어 정원

밝은 종이 바탕과 만지기 편한 무광 타일, 절제한 식물·자연 풍경을 사용한다. 글자가 가장 선명한 2D 세로 퍼즐로 만든다. 3D 엔진 전환은 하지 않는다. 지금은 기본 UI와 임시 그래픽으로 기능을 완성하고 이 명세대로 나중에 그래픽을 교체한다.

배경은 아이보리 #F7F3EA, 본문은 짙은 남회색 #293241, 완성 타일은 세이지 #4A7C59, 선택은 호박색 #D99A36, 보조 패널은 #EDF3F6다. 색만으로 상태를 구분하지 않고 테두리·체크·문구를 함께 사용한다. 실제 텍스트 대비는 제작 결과에서 검사하고 팔레트만으로 접근성 통과를 주장하지 않는다.

모서리는 부드럽고 그림자는 낮게, 버튼은 터치 영역 최소 44pt를 기준으로 검증한다. 숫자·타일 글자를 장식 효과보다 우선한다. 세 언어 폰트 라이선스와 누락 글리프를 확인하며 시스템 대체 폰트만으로 일관성을 보장하지 않는다. Noto Sans 계열을 후보로 검토하되 실제 포함 파일의 라이선스를 함께 보관한다.

게임 중 보드·랙·힌트·제출은 주요 화면 안에 배치하는 것을 목표로 한다. 도움말과 상세 정보는 접거나 별도 패널로 둔다. 현재 전체 스크롤 UI는 임시이며 작은 화면의 랙 잘림은 단계 2 개선 대상이다. 탭만으로도 모든 핵심 조작을 할 수 있고 스와이프는 추가 편의다. 미완성 정답은 개발용 표시에서만 보여준다.

## 에셋 목록

경로는 향후 산출물 위치이며 아래 그래픽 파일이 이미 있다는 뜻은 아니다. 상세 목록은 release/asset_manifest.json을 따른다.

| 묶음 | 수량 | 규격과 용도 |
|---|---|---|
| 앱 아이콘 마스터 | 1 | 1024×1024 PNG, 문자 없는 타일+잎 실루엣, iOS용 불투명 마스터 |
| 가로 워드마크 | 1 | 1600×400 투명 PNG, 게임 내 언어 문구는 별도 텍스트 |
| 배경 | 6 | 1440×2560 세로, 화면 채움 크롭 가능, 중앙 보드 영역 저대비, 글자 없음 |
| 타일 외형 | 5 | 256×256 투명 PNG: 기본/선택/완료/재사용/비활성, 글자는 런타임 |
| UI 아이콘 | 16 | 128×128 투명 PNG 또는 기존 UI와 맞는 벡터, 44pt에서 식별 |
| 버튼 외형 | 4 | 384×128, 9-slice 가능: 기본/강조/눌림/비활성, 문구 제외 |
| 수집 스탬프 | 6 | 256×256 투명 PNG, 6개 배경 테마와 일치 |
| 축하 효과 | 2 | 부드러운 반짝임·나뭇잎 조각, 과도한 점멸 없음 |
| BGM | 1 | 48초 이상 자연 루프 목표, 말소리·라이선스 불명 샘플 없음 |
| 효과음 | 10 | 선택/정답/보너스/힌트/오답/클리어/버튼/재화/보상/안내, 기존 6종 확장 |
| 스토어 이미지 | 3언어 각 5장 계획 | 실제 최종 빌드 화면 기반, 기기별 규격은 제출 시 확인 |

배경 테마는 햇살 정원, 숲길, 바닷가, 조용한 카페, 노을 언덕, 별빛 온실의 6개로 고정한다. 75레벨 단위로 사용하며 각 테마에 15레벨 챕터 5개가 있다. UI는 계절·문화·국기·텍스트가 박힌 이미지에 의존하지 않는다.

16개 UI 아이콘은 홈, 설정, 뒤로, 소리, 음악, 진동, 언어, 힌트, 지우기, 제출, 다음, 코인, 상점, 일일, 선물, 광고 보기다. 기능이 없는 버튼은 에셋이 있어도 노출하지 않는다.

영어·한국어·일본어를 하나의 장식 로고에 억지로 넣지 않는다. 레벨·가격·광고·상점·보상·힌트·설명은 전부 문자열 키로 렌더링한다. 구매 버튼에는 실제 StoreKit 현지 가격과 상품 내용을 표시한다. 광고 보기 버튼은 광고임을 명시하고 보상량을 미리 보여준다.

## 사운드 방향

짧은 나무·말렛 계열 선택음, 부드러운 상승 정답음, 낮은 음량의 오답음과 여유로운 앰비언트 BGM을 사용한다. 오답이 벌처럼 들리지 않게 한다. 기본 음량은 효과음 약 -18dB, 음악 약 -28dB에서 기기 청취 후 조정한다.

음악과 효과음은 독립 토글·볼륨을 제공하고 저장한다. 앱 일시정지·광고·외부 오디오 간섭 후의 복귀 규칙을 정한다. Windows의 재생·음소거 검증과 iOS 오디오 세션 검증을 구분한다. 사용자가 음소거했을 때 보상이나 클리어로 임의 재활성화하지 않는다.

## 아트 제작·교체 합격 기준

- 아트 지침·에셋 목록은 확정했으며 고해상도 일괄 제작은 후속 작업이다.
- Gemini는 명세·생성용 프롬프트·UI 문구·콘텐츠를 제공한다. 제공하지 않은 PNG/WAV를 제작 완료라고 부르지 않는다.
- 코인·상품·광고에 오해를 부르는 아이콘·가짜 할인·가짜 한정 시간·위압적 카피를 사용하지 않는다.
- 모든 외부 폰트·사전·이미지·오디오에 출처와 실제 사용 허용 범위를 기록한다. AI 출력에 존재하지 않는 라이선스를 부여하지 않는다.
- 원본 마스터, 게임용 축소본, 라이선스, 파일 크기와 투명 여백을 확인한 뒤 교체한다. 실제 iPhone 메모리·색상·텍스트 가독성은 Mac 인계 후 검사한다.

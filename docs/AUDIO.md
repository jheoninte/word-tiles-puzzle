# 오디오와 설정

## 현재 구현

- `GameAudio.gd`는 기존 6종에 button/coin/reward/notice를 더한 10종의 PCM 효과음과 4개 재생 풀을 제공한다. 기존 play_cue/set_enabled/streams/players 인터페이스를 유지한다.
- 선택·정답·보너스·힌트·오답·클리어는 기존 게임 이벤트와 연결되어 있다. 버튼은 설정 열기·효과음 재활성화에 연결했다. coin/reward/notice는 이후 상점·일일 보상·안내에서 사용할 준비된 큐다. 아직 없는 기능의 연동 완료로 보지 않는다.
- `audio/garden_loop.wav`는 48초, 22050Hz, mono PCM16 배경음이다. `python -B tools/generate_audio.py`로 재생성한다. 외부 샘플·녹음·다운로드 음원을 사용하지 않고 이 저장소의 악보 배열과 합성 코드로 만든다. WAV는 실제 실행 자산이므로 저장소에 포함한다.
- 기본 최대 게인은 효과음 -18dB, 음악 -28dB이며 각각 0~1 설정 게인을 추가로 적용한다. 기본 설정 게인은 효과음 0.8, 음악 0.65다.
- 헤더의 기존 소리 버튼과 설정의 전체 소리 버튼은 전체 음소거다. 설정에서 음악과 효과음을 각각 켜거나 끄고 음량을 조절한다. 전체 음소거는 개별 설정을 초기화하지 않는다. 음악 음량 0은 음악을 일시정지한다.
- 슬라이더는 즉시 오디오에 반영하고 마지막 변경 뒤 0.3초 후 전체 게임 스냅샷을 저장한다. 앱 포커스 상실·중단·종료 시 기존 즉시 저장도 유지한다.
- 포커스·앱 일시정지는 별도 사유로 기록한다. 한 사유만 해제해 다른 중단 사유를 무시하지 않는다. 이후 광고 어댑터는 `set_suspended(true, "ad")`와 종료 시 false를 연결할 수 있다. 실제 광고 SDK는 아직 없다.

## 저장

기존 `[progress]`에 `music_enabled`, `effects_enabled`, `music_volume`, `effects_volume`를 추가했다. 기존 `sound_enabled`는 전체 음소거 설정이다. 기존 commit_progress의 인자·신호·저장 경로는 바꾸지 않았다.

키 누락·잘못된 타입은 위 기본값을 쓴다. 음량의 유효한 숫자는 0~1로 제한하고 NaN/무한대는 기본값을 쓴다. boolean을 숫자로 취급하지 않는다. 오래된 저장이 전체 음소거 상태라면 음악이 새로 추가되어도 재생하지 않는다.

## 실제 검증과 남은 검사

Godot 4.7.2 / Windows의 분리된 QA 프로젝트에서 다음을 검사했다.

- 48초 배경음 길이·루프 경계, 효과음 10개 PCM·엔벨로프·재생 풀.
- 음악·효과음 독립 제어, 전체 음소거, 0 음량, 설정 저장·복원·슬라이더 저장 지연.
- 포커스/앱 중단/광고 가정 사유가 겹칠 때의 복귀, 음소거 임의 해제 방지.
- 이전 저장·잘못된 타입·범위 밖 값·NaN·무한대 처리, 음소거 이전 저장의 음악 자동 재생 방지.
- 375×667·480×854 설정 가로 넘침과 기존 게임 회귀.

로컬 검사 스크립트는 `dist/godot-release-foundation-smoke.gd`, 결과는 같은 이름의 `.log`에 있다. Dummy 드라이버 검사로 실제 청취를 대신하지 않는다. 음악의 취향·반복 피로, 실제 스피커·이어폰의 밸런스, iOS 무음 스위치·오디오 세션·다른 앱 음악·전화 중단·실제 광고 SDK 복귀는 Mac과 실기기에서 확인한다. 현재 오디오 기능 구현을 iOS 사운드 최종 승인으로 부르지 않는다.

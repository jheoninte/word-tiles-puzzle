# Gemini 작업 4: 첫 실행 튜토리얼

첨부 `gemini-onboarding-source.txt`에 경로별로 포함된 최신 원문을 기준으로 아래 작업만 수행한다. ZIP을 열 필요가 없다. 결과는 Codex가 실제 Godot 4.7.2에서 통합·검증한다.

```text
현재 Word Tiles Godot 게임에 첫 실행 튜토리얼을 구현하라.
첨부 텍스트의 FILE BEGIN / FILE END 사이에 있는 실제 소스를 먼저 읽어라. 기존 게임을 교체하거나 웹 전체 코드를 다시 출력하지 마라.

현재 상태:
- Godot 4.7.2에서 기본 3개 레벨, 탭/스와이프, 교차 글자 재사용, 보상, 오프라인 저장을 실행 검증했다.
- GameAudio가 실제 추가되어 선택·정답·보너스·힌트·오답·클리어 효과음을 제공한다. 그 파일을 덮어쓰거나 제거하지 마라.
- MainGame.tscn은 컨트롤러·GameAudio·SafeMargin/Scroll/Content를 갖고 있으며 MainGame.gd의 _build_ui()가 실제 UI를 만든다.
- GameManager.commit_progress()는 코인·좌표·보너스·소리·클리어 보상을 한 번에 저장한다. 기존 API와 SAVE_PATH를 유지해야 한다.

읽을 파일:
AGENTS.md
docs/RELEASE_PLAN.md
docs/GODOT_PLAYABLE.md
docs/GAME_DESIGN_SPEC.md
docs/DATA_SCHEMA.md
godot-project/scripts/MainGame.gd
godot-project/autoload/GameManager.gd
godot-project/scripts/SwipeRackController.gd
godot-project/scripts/LevelController.gd
godot-project/scripts/GameAudio.gd
godot-project/scenes/MainGame.tscn

구현 범위:
1. TutorialController.gd 같은 작은 모듈로 튜토리얼 상태를 분리하고 MainGame에는 UI·이벤트 연결만 최소 추가한다.
2. 모달로 게임을 막지 않는 짧은 안내 카드를 제공한다. 375x667 세로 화면에서 가로 잘림 없이 읽을 수 있어야 한다.
3. 세 단계:
   - 첫 글자 선택 안내. 실제 유효한 글자가 선택되면 다음 단계.
   - 단어를 만든 뒤 제출/스와이프 안내. 실제 미완성 정답을 맞혔을 때만 다음 단계. 오답·보너스·단순 버튼 클릭·힌트는 이 단계의 성공으로 취급하지 않는다.
   - 남은 칸 수량과 ↻ 교차 글자 재사용 안내. '계속 플레이'를 누르면 완료한다.
4. 모든 단계에서 건너뛰기를 제공한다. 건너뛰기와 완료는 완료 상태를 저장한다. 처음부터 다시 진행을 강요하지 않는다.
5. 기존 진행(레벨>0 또는 채워진 셀/보너스가 있음)이 있는 사용자는 자동 안내를 띄우지 않는다. 기존 플레이를 방해하지 않되 도움말에서 다시 볼 수 있다.
6. 완료 뒤에도 도움말 버튼으로 재생할 수 있다. 재생 때문에 완료 플래그나 게임 진행도를 초기화하지 않는다. 도움말 버튼은 좁은 헤더를 억지로 늘리지 말고 적절한 위치에 둔다.
7. 오버레이를 쓰면 종료·건너뛰기·재생 시 포인터와 선택 상태를 안전하게 초기화한다. 입력 예외와 재생 완료 신호가 중복 연결되지 않아야 한다.
8. 설명을 보여주거나 다음 안내로 넘어가는 행위로 코인·보드·레벨·클리어 보상·힌트 비용이 변하면 안 된다. 실제 게임 조작에서 발생하는 기존 보상만 유지한다.

저장:
- GameManager에 tutorial_completed: bool을 추가하고 기존 ConfigFile [progress]에 저장한다. 이전 저장에 키가 없거나 타입이 잘못되면 false다.
- 기존 load_progress() 초기화 경로에도 반영한다. 완료 여부가 이미 true인 상태에서 도움말을 다시 열어도 false로 되돌리지 않는다.
- 기존 공개 함수 시그니처·신호·commit_progress() 호출 호환을 유지한다. 필요한 필드/메서드/신호만 추가한다.
- 완료/건너뛰기는 MainGame의 현재 게임 스냅샷 저장 흐름과 통합한다. GameManager의 오래된 필드로 현재 보드나 재화를 덮어쓰지 마라.
- 저장 실패 시 기존 오류 표시를 가리지 마라. 프로세스를 다시 실행해도 무조건 완료 처리되는 것처럼 주장하지 마라.

유지할 사항:
- 오프라인 동작, 기존 저장 파일, 교차 입력/보너스 규칙, 선택/제출/드래그 취소, 힌트·다음 레벨, 소리 토글과 실제 효과음.
- 씬과 Godot 스크립트의 기존 공개 인터페이스.
- GameAudio와 기존 보상 로직을 일반 리팩터링하지 마라.
- 레벨 데이터·웹·레벨 생성기·검증기는 이번 변경 대상이 아니다.
- HubGame, 클라우드, 리더보드, 광고, IAP, 분석 SDK는 이번 요청에 없다. 외부 스튜디오 문서 지침을 이 저장소 요구사항으로 가져오지 마라.
- 인라인 코드 주석을 추가하지 말고 설명은 Markdown 문서에 적어라.

검증 요구:
- 첫 실행/유효 선택/정답/오답/보너스/힌트별 튜토리얼 전이.
- 각 단계의 건너뛰기, 완료 저장 후 재시작, 중간 종료 후 복귀, 기존 저장의 필드 누락·잘못된 타입.
- 진행이 있는 사용자 자동 표시 제외와 도움말 재생.
- 도움말 반복 열기/닫기, 포커스 상실, 스와이프 중 열기, 소리 끄기와의 호환.
- 튜토리얼 전후 게임 상태가 실제 조작 외에는 변하지 않는지 확인.
- 375x667·480x854 UI와 하단 스크롤, 기존 세 레벨 완료/저장 복원에 회귀가 없는지 확인.
- 실제 엔진 실행이 불가능하면 미검증으로 적어라. 코드 검토를 실행 검증이라고 부르지 마라.

출력:
- 변경·추가 파일만 경로별로 생략 없는 전체 코드를 제공한다.
- docs/ONBOARDING.md에 단계·저장·연결 방법과 실제 검증/미검증을 적는다.
- 원본 파일을 읽을 수 없으면 추측하지 말고 해당 경로를 요청한다.
- 코드와 작업 관련 보고만 출력한다. 요청하지 않은 클라우드 기능이나 다른 게임 코드는 출력하지 마라.
```

# Godot 첫 실행 안내

## 동작

`TutorialController.gd`가 상태를 관리하고 `MainGame.gd`가 안내 카드와 게임 이벤트를 연결한다. `MainGame.tscn`에 TutorialController 자식 노드가 있다. 안내는 전체 화면 스크롤 안의 카드이며 게임 입력을 차단하지 않는다. 작은 화면에서는 위로 밀어 타일·하단 버튼에 접근한다.

1. 처음 실행하면 글자 선택을 안내한다. SwipeRackController가 유효한 글자를 선택해 비어 있지 않은 `word_changed`를 보낼 때만 다음 단계로 간다.
2. 단어 제출을 안내한다. MainGame이 실제 미완성 보드 정답을 채운 분기에서만 다음 단계로 간다. 오답, 보너스, 힌트, 선택 취소와 제출 버튼만 누르는 동작은 이 단계를 완료하지 않는다.
3. 남은 빈 칸 수와 `↻` 정답 글자 재사용을 설명한다. `계속 플레이`로 완료한다.

어느 단계에서나 건너뛸 수 있다. 안내만으로 보드·코인·레벨·클리어 보상을 바꾸지 않는다. 연습 중 실제 정답·힌트·보너스 보상과 비용은 기존 규칙대로다. 단계가 바뀌어도 글자 랙이 움직이지 않도록 설명 영역 높이를 확보한다.

레벨 인덱스가 0보다 크거나 유효한 채움 좌표·보너스가 있는 기존 사용자는 자동 안내를 보지 않는다. 자동 안내 제외와 완료 플래그는 별개다. 도움말 버튼으로 다시 열 수 있고, 안내 중 도움말을 누르면 종료·완료 처리한다. 이미 보드를 모두 완성했다면 도움말은 실행할 수 없는 연습 단계 대신 마지막 설명을 연다.

도움말 재생·종료·건너뛰기·완료 때 선택과 포인터를 초기화한다. 앱 포커스 상실 때도 기존 입력 취소·저장을 유지한다. 신호는 씬 시작 시 한 번 연결하고 재생 때 다시 연결하지 않는다. 카드 Tween은 씬에 귀속되며 재전환·종료 시 기존 Tween을 중지한다.

## 저장 호환

`GameManager`의 기존 `user://word_tiles_save_v1.cfg` 안 `[progress]`에 boolean `tutorial_completed`만 추가한다. 누락되었거나 boolean 타입이 아니면 false다. `load_progress()`는 로드 전 기본값으로 초기화한다. 기존 공개 함수·신호, 여섯 인자를 받는 `commit_progress()`는 유지한다.

건너뛰기·완료 시 GameManager의 완료 플래그를 true로 설정하고 MainGame의 `_save_current()`로 현재 좌표·보너스·코인·소리·보상을 함께 저장한다. 도움말 재생으로 완료 플래그를 false로 바꾸지 않는다. 실패 시 기존 오류 표시를 유지하고 이전 파일을 보존한다. 메모리에서 닫혔더라도 저장 성공 전 강제 종료하면 다음 실행에서 다시 안내가 나올 수 있다. 이후 게임 저장이나 도움말 종료는 저장을 재시도한다.

첫 선택만 한 뒤 종료하면 다음 실행에서 첫 단계로 시작한다. 정답·힌트·보너스로 진행도가 저장된 뒤 중간 종료하면 기존 사용자와 동일하게 자동 안내를 생략하며 도움말로 재생한다. 중간 단계 번호 자체는 저장하지 않는다.

## 실제 실행 검증

Windows의 Godot 4.7.2에서 실제 게임 저장과 분리한 `Word Tiles Codex QA` 프로젝트로 검사했다.

- 씬·스크립트 임포트, 첫 실행, 잘못된 선택·오답·보너스·힌트의 단계 이동 차단, 유효 선택과 실제 정답의 단계 이동.
- 세 단계 각각 건너뛰기, 중복 종료 방지, 완료 후 저장 복원, 중간 종료, 누락·문자열·정수·boolean 저장 필드 처리.
- 레벨·좌표·보너스 각각의 기존 진행 자동 안내 제외, 도움말 반복 재생, 완료된 보드의 설명 표시, 완료 플래그 유지, 중복 신호 연결 방지.
- 포커스 상실과 활성 포인터 초기화, 재생 시 선택 취소, 음소거·재활성화, 안내 전후 게임 상태 불변, 현재 스냅샷 저장 일치.
- 저장 임시 경로를 디렉터리로 막아 실패를 만들고 오류 표시·기존 파일 보존·완료 플래그 미저장을 확인했다.
- 375×667·480×854에서 가로 넘침 없음, 단계 전환 시 랙 위치 유지, 스크롤로 하단 도움말 접근을 검사했다. OpenGL Compatibility 렌더러로 두 크기의 세 단계와 스크롤 화면을 캡처해 확인했다.
- 기존 세 레벨 완료·교차 입력·탭/합성 터치·힌트·보너스·보상 중복 방지·저장 실패 검사와 효과음 PCM·음소거 검사를 실행했다.

검사 스크립트와 로그는 로컬 `dist/godot-onboarding-smoke.gd`, `dist/godot-onboarding-smoke.log`, `dist/godot-smoke.log`, `dist/godot-audio-smoke.log`에 있다. 실제 렌더링은 `dist/onboarding-375-step1.png` 등이다. dist는 배포·Git 추적에서 제외한다.

## 미검증

iOS 실기기의 손가락 입력·안전 영역·앱 중단 복귀·오디오 세션, VoiceOver 및 기기별 접근성, 실제 초보 사용자의 안내 이해도는 미검증이다. 오디오 자동 검사는 Dummy 드라이버로 수행했으며 스피커 청취 검증이 아니다. Mac에서 네이티브 빌드·실기기·TestFlight 검증을 이어간다.

이번 통합은 Gemini의 튜토리얼 상태 분리·카드·이벤트 연결을 바탕으로 보완했다. 범위 밖 클라우드·리더보드 코드는 반영하지 않았고 웹과 레벨 규칙을 변경하지 않았다.

이전 답변의 웹 프로토타입 수정안은 폐기한다. 이번 작업은 기존 Godot 게임의 첫 실행 튜토리얼 구현뿐이다.

함께 첨부한 gemini-onboarding-source.txt는 ZIP이 아닌 UTF-8 일반 텍스트다. 각 FILE BEGIN: 경로 / FILE END: 경로 사이에 현재 파일의 전체 원문이 들어 있다. 이 텍스트를 직접 읽고 작업하라.

1. docs/GEMINI_ONBOARDING_TASK.md의 요구사항을 따르라. 기존 MainGame.gd, GameManager.gd, 씬과 컨트롤러의 실제 인터페이스를 유지하라.
2. 첫 유효 글자 선택 → 미완성 보드 정답 제출 → 남은 수량 및 ↻ 설명의 3단계 안내, 건너뛰기·완료 저장, 도움말 재생을 구현하라.
3. 이미 진행한 사용자는 자동 안내에서 제외하라. 실제 게임 조작 없이 코인·보드·보상·레벨을 바꾸지 마라. 기존 오프라인 저장·효과음·입력 처리를 유지하라.
4. 외부 game-studio 문서의 웹·클라우드 요구사항을 가져오지 마라. 웹, HubGame, 리더보드, IAP, 광고는 변경 범위가 아니다.
5. 먼저 읽은 MainGame의 UI 생성 함수, GameManager의 저장 함수와 저장 경로를 짧게 명시하라. 원문이 보이지 않으면 필요한 경로만 요청하고 대체 게임 코드를 만들지 마라.
6. 변경·추가 파일만 경로와 생략 없는 전체 코드로 제공하라. docs/ONBOARDING.md를 포함하고, 실제 실행 검증과 미검증을 구분하라. 엔진 실행 없이 실행 검증했다고 쓰지 마라.

이 파일과 첨부 소스에 없는 이전 답변의 코드는 사용하지 마라.
